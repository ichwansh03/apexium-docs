# ✨ Features

Every tool you need to master Salesforce debugging.

## 📋 Debug Log Management

- **Persistent storage** – keep logs beyond Salesforce's 24‑hour retention.
- **Filter & search** – by user, time, log level, or Apex class.
- **Export** – JSON, CSV, or raw format.

## ⏰ Trace Flag Automation

- Schedule start/end times with recurrence (daily, weekly, custom).
- Scope to user, class, or entire org.
- Full history of past & upcoming traces.

## 📊 Apex Coverage Monitoring

- On‑demand or scheduled coverage reports.
- Track coverage trends over time.
- Alerts when coverage drops below threshold.

## 🔍 Metadata Change Tracking

- Detect changes to Apex classes, triggers, VF pages, etc.
- Audit trail with who, what, and when.
- Diff view between versions.

## 🖥️ CLI & Web UI

- Full‑featured CLI with auto‑completion.
- Optional web dashboard for visual monitoring.
